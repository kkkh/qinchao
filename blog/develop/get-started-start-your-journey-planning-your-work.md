# 规划工作

组织工作并跟踪进度，以便始终知道接下来要生成的内容。

在编写代码之前，先明确你想要构建的内容，并跟踪你的进度。 在本教程中，你将使用 GitHub Issues 和 Projects 来规划和组织网站首个功能的工作。

## 先决条件

* 一个 `stargazers-log` 存储库。 如果尚未创建它，请参阅 [在 GitHub 上为项目创建存储库](https://docs.github.com/zh/get-started/start-your-journey/creating-a-repository-for-your-project-on-github)。

## 创建议题

议题用于跟踪您的软件项目中的想法、任务和缺陷。 为你将构建的第一个功能创建一个列表：在你的网页上显示已加星标的仓库。

1. 在存储库的 `stargazers-log` 主页上，单击“ **问题**”。
2. 单击“新建问题”。
3. 在 **“添加标题** ”字段中，键入 `Display a list of starred repositories`。
4. 在说明字段中，添加一些要生成的内容的详细信息，例如“在主页上显示星形存储库列表”。
5. 单击 **“创建”** 。

## 创建项目板并导入问题

Projects 为你提供可视化表、版块和路线图，用于组织和跟踪软件项目的问题。 在本教程中，你将为 `stargazers-log`该用户创建一个用户项目板。

1. 在 GitHub右上角 GitHub单击个人资料图片，然后单击 **“个人资料**”。
2. 单击“ **项目**”。
3. 单击“新建项目”。\*\*\*\*
4. 在 **模板** 下，选择 **看板**。
5. 在项目名称字段中，键入 `Stargazers log`。
6. 保持勾选 **从存储库导入项**，以将您最近创建的议题导入到看板中。
7. 单击“**创建项目**”。

## 全面推进工作

看板中的列代表你的工作的各个阶段。 随着进展，移动每个项目以显示其状态。

1. 在项目板上，找到 `Display a list of starred repositories` 列中的\*\*\*\* 项。
2. 将项拖到 **“正在进行** ”列中，以显示已启动工作。

稍后你将返回看板，在功能上线后将该项移至**完成**。

## 添加后续问题

创建一个或多个问题来描述你以后要处理的网站的想法和功能。 例如，您可以创建一个议题，用于：

* 向网站添加搜索功能
* 改进星形存储库列表的样式
* 允许使用编程语言（如 JavaScript、Python 或 Go）筛选星标存储库

将每个新问题添加到项目板中，并在开始处理该问题后将其移至 **正在进行**。

## 你完成的工作

| 任务      | 结果                          |
| ------- | --------------------------- |
| 创建了问题   | 你已将第一项功能记录为可跟踪的任务。          |
| 创建了项目板  | 你创建了一个看板来整理并跟踪你的工作。         |
| 已跟踪您的进度 | 你已将问题添加到看板，并将其移动到进度中。       |
| 添加了更多问题 | 你创建了新的问题，用于记录你的网站后续需要开展的工作。 |

## 后续步骤

* 规划工作后，将存储库引入计算机，以便可以开始编写、存储和更新网站代码。 继续前往 [在本地连接到您的代码库](https://docs.github.com/zh/get-started/start-your-journey/connecting-to-your-code-locally)。
