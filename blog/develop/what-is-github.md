# 什么是 GitHub？

GitHub 是一个平台，支持整个软件开发过程，从规划工作到部署和操作软件。

GitHub 是用于构建软件的平台。 无论是启动新项目还是参与现有项目， GitHub 都会将所需的工具和工作流汇集到软件开发生命周期的每个阶段（SDLC）。

## GitHub 以及软件开发生命周期

软件开发生命周期描述了软件项目从第一个想法到在生产环境中运行代码的阶段。
GitHub 旨在支持该过程的每个阶段。

| 阶段      | 你可以在 GitHub 上执行的操作            |
| ------- | ----------------------------- |
| Plan    | 跟踪工作、设置里程碑和组织长期项目。            |
| Create  | 编写和存储代码，安全地开发新功能，并创建更改的明确时间线。 |
| Review  | 建议对项目进行更改，与审阅者讨论更新，并应用反馈。     |
| 测试      | 在合并之前自动执行检查以验证每个更改。           |
| Deploy  | 交付具有自动化部署工作流和发布管理的软件。         |
| Operate | 监视应用程序、管理依赖项以及查找和修复安全问题。      |

无需一次性使用每个阶段。 许多人一开始只是使用一个代码仓库和几个议题，随后随着项目的发展，逐步扩展对该平台的使用。

## GitHub 和 Git

GitHub 基于开源软件 Git。

Git 是一个版本控制系统，用于跟踪对文件的更改。 它允许你自行处理项目副本、记录更改的历史记录，并安全地将你的工作与其他人的更改合并。

GitHub 基于 Git，既在云端托管称为 **仓库** 的 Git 项目，又提供规划和协作工具，让团队更轻松地开展协作。

有关 Git 的详细信息，请参阅 [关于 Git](https://docs.github.com/zh/get-started/using-git/about-git)。

## GitHub 适合我吗？

GitHub 学生、开发人员、项目经理、安全团队、数据科学家、研究人员、人力资源和法律人员以及各种规模的组织中的许多其他人员都使用。

人们使用 GitHub 的一些最常见原因是：

* 使用版本控制存储和管理代码。
* 编写代码、查看代码、管理安全漏洞和更新。
* 在项目中协作和交流。
* 为开源软件做贡献。
* 跟踪和管理项目。
* 自动执行 CI/CD、测试和部署等软件开发工作流。
* 展示并分享作品。
* 发布和发行软件包。
* 托管文档和网站。
* 参与软件开发社区和讨论。
* 使用 AI 驱动的工具和代理帮助更快地编写、理解、审阅和自动化代码开发。

## 从哪里开始？

如果你不熟悉 GitHub 和不熟悉 Git，我们建议使用 [开始你的旅程](https://docs.github.com/zh/get-started/start-your-journey) 类别中的文章。 本文介绍如何执行软件开发人员使用的 GitHub常见任务，例如：

* **为软件项目创建存储库** 并存储代码 GitHub，请参阅 [在 GitHub 上为项目创建存储库](https://docs.github.com/zh/get-started/start-your-journey/creating-a-repository-for-your-project-on-github)。
* 通过创建问题和跟踪项目工作来**规划工作**。
* **连接到本地计算机上的代码** ，并使用 GitHub Desktop 应用程序通过 Git 管理代码更改。
* **编写和存储代码**，（可选）与 AI 助手配对，并将更改与 GitHub同步。
* 通过创建拉取请求，并在合并前审查自己的更改，来**审查拟议的代码更改**。
* 使用自动化部署工作流**部署你的网站**，从而让你能够发布软件项目的基础网站。
